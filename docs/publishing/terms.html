1. Purpose

Warframe Tracker provides authenticated inventory organization, collection progress, relic information, farming references, goals and companion features. Information is provided for convenience and may become incomplete or outdated as the game changes.

3. Inventory access

Inventory information is received through Overwolf's game-event package. The app requires an explicit Send action and a separate preview confirmation before normalized collection changes are stored. It does not request Warframe credentials or modify game files, memory or network traffic.

4. Data and privacy

A raw GEP capture remains local until you explicitly send it for review. Confirmed normalized collection data is stored by the authenticated Tracker service. Read the Privacy Policy for processing, retention and deletion details.
