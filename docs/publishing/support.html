Warframe Tracker Support

Public help for installation, inventory capture and data protection.

Report an issue

Include your Windows, Overwolf and app versions, steps to reproduce and the visible error message. Do not attach raw inventory data.

Create a GitHub issue

Protect your information

Never publish passwords, two-factor codes, tokens, Overwolf keys, private email addresses, account IDs or raw inventory JSON.

Delete local and cloud data

Use Discard local capture to remove a pending GEP snapshot. Uninstalling removes local Native storage. To request deletion of an authenticated Tracker account and its confirmed cloud collection, open a support issue containing only the Tracker username and request a private contact channel if identity verification is needed.

Soporte en español

Para informar un problema o solicitar la eliminación de la cuenta y sus datos en la nube, abre una incidencia indicando las versiones y los pasos para reproducirlo. No publiques contraseñas, tokens, identificadores ni el JSON bruto del inventario.
