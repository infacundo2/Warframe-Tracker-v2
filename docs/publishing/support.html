Soporte de Warframe Tracker

Ayuda pública para instalación, captura de inventario y protección de datos.

Informar un problema

Abre una incidencia indicando la versión de Windows, la versión de la aplicación, los pasos para reproducir el problema y el mensaje visible.

Crear una incidencia en GitHub

Protege tu información

No publiques contraseñas, tokens, claves de Overwolf, correos privados ni el JSON bruto del inventario.

Eliminar datos locales

Cierra y desinstala Warframe Tracker. Después elimina %APPDATA%\warframe-tracker-desktop. Esto elimina permanentemente los perfiles e inventarios guardados en ese PC.
