Warframe Tracker Support

Public help for installation, inventory capture, and data protection.

Report an issue

Include your Windows version, app version, steps to reproduce, and the visible error message.

Create a GitHub issue

Protect your information

Never publish passwords, tokens, Overwolf keys, private email addresses, or raw inventory JSON.

Delete local data

Close and uninstall Warframe Tracker, then delete %APPDATA%\warframe-tracker-desktop. This permanently removes profiles and inventory stored on that PC.
